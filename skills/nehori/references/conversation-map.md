# 会話の見取り図

長い相談、希望の訂正、目的の変更、次の作業への引継ぎで読む。これは会話内の整理用で、作成必須の記録ファイルや個人プロフィールではない。短い相談では必要な項目だけを扱う。

## 分けて持つもの

| 項目 | 入れるもの |
|---|---|
| 今回の目的 | 何の相談で、今は何を得たいか。具体候補、イメージ、意見の整理など |
| 発言と例 | 本人が実際に述べた言葉、示した例。必要な短い引用と会話中の位置 |
| 現在の意向 | 本人が述べた、または確認した希望。使う場面と確認範囲 |
| 解釈候補 | AIが発言をつないで考えた説明。まだ本人の希望とは扱わない |
| 未決定と委任 | 分からない、こだわりがない、任せたいところ。委任された範囲 |
| 訂正 | どの解釈を外し、どの条件を維持するか |
| 次の一手 | 質問、見本、具体候補、検索計画、区切りのうち、今の目的に合うもの |

本人が自発的に述べた希望と、AIの見本を見て採用した希望には、その違いが分かる印を付ける。どちらも現在の意向になり得る。未回答や案への無反応は、同意・不満・好みの証拠にしない。

## 更新する

新しい返事のうち、今回の判断が変わる部分だけを更新する。本人が訂正したら、古い解釈と、それを根拠にした案を外し、影響しない条件は保つ。
目的がイメージ作りから具体候補探しへ変わったら、次の一手も切り替える。過去の目的を満たすための質問を続けない。参考の経験への返答と、本人が示した目的の変更を分けて更新する。
複数の希望が食い違って見える場合は、使う場面や優先順位が違う可能性を残す。矛盾を埋める動機や人格を作らない。

### 訂正の例（架空）

- これまでの解釈候補: 暗い画面が好き。
- 新しい発言: 「暗い画面が好きなのではなく、眩しい装飾を避けたい。白い画面でもよい。文字は大きく。」
- 更新後の意向: 眩しい装飾を避ける。白い画面も候補。大きな文字は維持。
- 外すもの: 暗色好みという解釈と、暗色だけに絞った提案。
- 次の一手: 色の好みを聞き直すより、装飾を抑えた白地と暗地の見本を比べる。

## 次の一手を選ぶ

| 今わかっていること | 進め方 |
|---|---|
| まだ比較できる像がなく、答えも浮かばない | 低リスクの仮の見本を見せる |
| 不足する一条件で、候補や提案が大きく変わる | その条件だけを聞く |
| 具体候補を求め、候補を分ける条件が足りている | 確認済みの候補を見せるか、外部検索の計画を示して了承を待つ |
| 全案が外れた、言葉の意味や目的が変わった | 影響する解釈を更新し、二つの経路で広げ直す |
| 本人が使える表現や基準ができた、または終了を希望した | 確認できた意向と未決定を返して区切る |

外部検索や永続保存の権限は、この見取り図から生まれない。[本体の許可と境界](../SKILL.md)に従う。

## 本人へ返すとき

台帳全体ではなく、理解の確認や次の作業に必要な部分を自然な文で返す。毎ターン同じ見出しを出さない。短い反映は訂正を受けるために使い、結論への同意を誘導しない。
引継ぎでは、確認した希望とその範囲、未決定・委任、外した案、次に行うことを必要な分だけ伝える。推測を確認済みに格上げしない。
本人が記録を頼んだ場合だけ、目的と保存先への了承を確かめてから必要な内容を保存する。会話の全文保存や恒久的な人物像の蓄積を、この参照の既定動作にしない。
